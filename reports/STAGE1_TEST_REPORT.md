**已知問題：**

1. 瀏覽器驗證阻礙：環境沒有 Sites 指定的 `cua_repl.js`，工具清單也無瀏覽器控制介面。依 managed preview 規定跳過瀏覽器 QA；不能保證所有裝置無明顯版面錯誤。待補桌面、平板、手機實際驗證。
2. file:// 自動複製通常被瀏覽器限制；已提供選取文字的手動備援。安全來源 Clipboard API 成功與失敗分支僅以模擬 API 測試，尚待實際系統剪貼簿確認。
3. 教材為通用教師示例，未對應特定年級、版本與課綱代碼，正式使用前須按學段查核。植物與導熱資料皆為模擬，非實驗實測。
4. 尚無外部科教專家審查或學生試作回饋；完整 V1.0 原始規格未附，僅能依本次文件列出的需求保留後續範圍。
5. 指定交付輸出目錄無寫入權限，成果改存工作區 `/workspace/output`。未生成可用的指定輸出目錄下載連結；ZIP 已在工作區備妥。

**使用者驗收方式：**

1. 解壓縮 `science-literacy-stage1.zip`，進入 `science-literacy` 資料夾，雙擊 `index.html`。
2. 點主導覽閱讀四個模組；切換兩組比較、開關解析、逐一點六個步驟。
3. 三組提示詞各複製一次並貼入記事本；若出現備援框，按 Ctrl+C 或手機長按複製。
4. 開啟官方來源；檢查模擬標示、科學推理與教學內容是否符合任教需求。
5. 縮放視窗並以手機操作；確認導覽、文字、按鈕可見且沒有水平捲動。這些畫面檢查本次尚未執行，請勿預設通過。
6. 閱讀本報告及進度文件，提出修改，或明確授權下一階段。

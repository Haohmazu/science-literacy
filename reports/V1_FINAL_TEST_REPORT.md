**已知問題：**

1. **實機驗證阻礙**：環境沒有 Sites 指定的 cua_repl.js，工具搜尋無瀏覽器控制介面。依 managed 規則未啟動替代伺服器或瀏覽器路徑。不能確認所有裝置無明顯版面錯誤。
2. **附件交付阻礙**：指定 /codex 輸出目錄在本環境不可用，先前建立遭作業系統權限拒絕；可用工具沒有通用附件上傳。成果只在 /workspace/output，這不是使用者電腦路徑，也沒有可用下載連結。不能宣稱交付完成。先前私人發布問題尚未獲同意，本次未發布。
3. localStorage 及下載能力依瀏覽器、路徑與來源而異；草稿不跨裝置、不跨網址同步，清瀏覽器資料或無痕模式可能遺失。提供失敗提示與 TXT 備份。
4. M05 與 M08 當頁紀錄不存入 M06 草稿，重新整理會清除。介面及 README 有說明。
5. 教材版本只是設定，沒有出版社內容庫；課綱留白時不杜撰代碼。AI 生成內容須在外部工具取得並經教師查證，本站不自動審題認證。
6. 本次未提供完整 V1.0 原始需求書，無法核對 V1.1 未重述的細節。自編教學內容尚未經外部專家、教師或學生試作驗證。
7. GitHub Pages 步驟按一般靜態網站流程撰寫，但未在帳號實際部署；不能稱部署驗收已通過。

**使用者驗收方式：**

前提：先取得實際可下載的附件；目前交付阻礙尚未排除。

1. 完整解壓 science-literacy-v1.0-review.zip，進入 science-literacy，雙擊 index.html；或直接開 science-literacy-standalone.html。
2. 依 README 的 Windows 11 十二步驗收 M01～M08；先驗證預設總計，再編輯藍圖計算。
3. 切換四模式，確認分析／改題／審題缺原題時停用匯出；填原題後產生不同任務提示詞。
4. 測試複製與 TXT 下載，用記事本核對繁體中文全文；儲存草稿、更改設定、讀取復原、關閉重開相同網址讀取、清除後確認無草稿。
5. 完成 M08 活動、檢核及反思，匯出紀錄；重新整理應清除當頁進度。
6. 以桌面、平板、手機及鍵盤檢查版面與可操作性。GitHub Pages 教學位於 README，若要發布需由使用者決定並執行或明確另行授權。
7. 檢查已知限制，決定接受、要求修改或暫停。沒有預設正式驗收通過。

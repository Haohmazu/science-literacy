**已知問題：**

1. 環境沒有 Sites 指定的 cua_repl.js，工具搜尋也未提供瀏覽器控制。依 managed preview 規則跳過瀏覽器 QA，未啟動替代伺服器或控制路徑。第一階段既有版面驗證缺口仍存在。
2. 直接開啟 index.html 可能無法自動複製；已提供手動複製。Clipboard API 成功分支為模擬測試，系統剪貼簿尚待實測。
3. 檢核及作答僅存在當頁記憶體；重新整理會清除。應先複製審題文字另存。localStorage 草稿屬第三階段，未提前實作。
4. 提示詞與 AI 審題皆為預寫教學範例，未實際送交外部 AI。無 API、無即時生成，無品質認證。
5. 未指定年級／教材版本／課綱代碼，科學例題與閱讀難度須由教師適齡性查核。十大地雷是本站自編整理，非官方清單。完整 V1.0 原始文件未提供的細節仍無法核對。
6. 指定 /codex 交付目錄在目前環境不存在且先前無寫入權限；ZIP 已存 /workspace/output，但未建立可用的指定目錄下載連結。

**使用者驗收方式：**

1. 解壓縮 science-literacy-stage2.zip，進入 science-literacy 資料夾，雙擊 index.html；完整檔案須放在一起。
2. 點「一題四用」，原題先不選送出，應提示選答案；選 B 送出應答對，選其他選項應提示再想一想並提供解析。
3. 切換四階段；改寫題 A、新題 C。試答錯誤選項，切換離開再回來，確認作答保留；按重新作答應清空該題。
4. 核對表格數據、模擬標示與計算。勾選三題比較欄位，全部取消應有提示。手機表格可左右捲動。
5. 每階段複製提示詞貼到記事本；出現手動文字框時選取後 Ctrl+C，手機長按複製。
6. 開啟「審題檢核」，展開十大地雷、改對象、填代稱與多行備註、勾選部分項目。匯出後確認已查核及待檢核均列出，複製貼到記事本。
7. 按重設，確認勾選、代稱與備註清空，對象回改寫題，預覽同步。
8. 回到 M01／M03／M07 操作原有功能。桌面、手機、平板畫面與實際複製需補驗，不可預設已通過。
